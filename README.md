# Tutoring School Database Management & Analytics System

Relational database and SQL analytics project designed to support tutoring-school operations and business analysis.

## Project Overview
This project designed a relational database for managing six core areas:
- Users
- Courses
- Course Sessions
- Video Lessons
- Enrollments
- Payments

The goal was to build a structured database that supports both operational data management and analytical SQL queries.

## Database Design
The system includes:
- Primary and foreign keys
- NOT NULL, UNIQUE, CHECK, and DEFAULT constraints
- Relationships between core entities
- Enrollment as a junction entity between students and courses

## Automation
Database triggers were implemented to automate business rules, including:
- Recorded-course expiration dates
- Enrollment count updates
- Enrollment count adjustments after cancellations

## Analytics
Analytical SQL queries were developed to examine:
- Enrollment behavior
- Course conversion
- Payments
- Cancellation rates
- Revenue and potential revenue loss
